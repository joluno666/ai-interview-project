# AI 面试项目：本地大模型与YOLO Web应用

## 项目简介
本项目完成了本地大模型（Ollama）的部署、API接入，以及YOLO目标检测的推理部署，最终构建了一个Flask Web应用。用户在网页上可以实现与大模型聊天，以及上传图片进行YOLO目标检测。

## 环境要求
- Ollama（本地大模型服务）
- Python 3.x
- 依赖库：`pip install ultralytics flask requests opencv-python`

## 如何运行
1. 启动 Ollama：`ollama run qwen2.5:0.5b`
2. 确保模型文件 `yolov8n.pt` 位于根目录（防止网络超时自动下载失败）
3. 启动后端：`python app.py`
4. 浏览器访问：`http://localhost:5000`

## AI 使用说明
本项目代码由 AI 辅助生成。我负责了环境搭建、解决网络问题、命令行测试、后端 API 调试以及前端排错。在遇到前端DOM渲染问题时，我通过浏览器开发者工具（F12）进行了排查，确保后端接口逻辑的稳定。

## 遇到的困难与解决
- **YOLO模型下载失败**：由于国内网络环境，直接通过代码下载 `yolov8n.pt` 会超时，通过手动下载模型并放置在根目录解决。
- **前端渲染异常**：在前后端联调时遇到浏览器控制台报错，通过排查网页元素（Elements）和强制刷新解决了缓存/渲染问题。
- **GitHub网络访问**：在提交代码时遇到网络限制，最终通过使用网络加速工具（Steam++）成功将项目推送至云端。
